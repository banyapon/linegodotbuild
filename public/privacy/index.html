1. ผู้ดูแลบริการและขอบเขต

โครงการ LINE × Godot Build ดูแลโดยเจ้าของบัญชี GitHub banyapon ซึ่งเป็นผู้รับผิดชอบการประมวลผลข้อมูลสำหรับบริการนี้ นโยบายนี้อธิบายการใช้ข้อมูลบนเว็บไซต์ linegodotbuild.vercel.app และบอต LINE ที่เชื่อมกับโครงการ เพื่อรับคำสั่ง build เกมผ่าน GitHub Actions

2. ข้อมูลที่ประมวลผล

  • ข้อมูลจาก LINE ได้แก่ User ID ประเภทแหล่งที่มาของข้อความ ข้อความคำสั่ง รหัสเหตุการณ์ และ reply token ระบบรับข้อมูลเหล่านี้ผ่าน webhook เพื่อตรวจสอบสิทธิ์และตอบกลับ
  • ข้อมูลงาน build ได้แก่ repository, branch, เป้าหมายการ export, รหัสคำขอ สถานะงาน และลิงก์ผลลัพธ์ โดยส่ง LINE User ID ไปยัง workflow เพื่อแจ้งผลให้ผู้สั่งงาน
  • ข้อมูลทางเทคนิคที่ผู้ให้บริการโครงสร้างพื้นฐานอาจบันทึก เช่น IP address เวลาเข้าถึง URL สถานะการตอบกลับ และบันทึกข้อผิดพลาด
  • ข้อมูลที่ท่านส่งให้ผู้ดูแลเมื่อขอความช่วยเหลือหรือขอใช้สิทธิเกี่ยวกับข้อมูล

ระบบไม่ได้เรียกดูรายชื่อเพื่อน รูปโปรไฟล์ หรือประวัติแชตทั้งหมดจาก LINE และไม่มีระบบวิเคราะห์โฆษณาหรือคุกกี้ติดตามที่โครงการเพิ่มเองบนหน้า Static ปัจจุบัน บริการภายนอกอาจมีคุกกี้และการบันทึกข้อมูลตามนโยบายของตน

3. วัตถุประสงค์และเหตุในการใช้ข้อมูล

ใช้ข้อมูลเพื่อยืนยันผู้มีสิทธิ์รับบริการ รับและดำเนินคำสั่ง build ป้องกันคำสั่งซ้ำ แจ้งสถานะ แก้ไขปัญหา รักษาความปลอดภัย และตอบคำขอของท่าน การประมวลผลที่จำเป็นต่อคำสั่งของท่านเป็นไปเพื่อให้บริการตามที่ร้องขอ ส่วนการป้องกันการใช้งานผิดวัตถุประสงค์และการดูแลระบบเป็นไปเพื่อประโยชน์อันชอบด้วยกฎหมาย โดยคำนึงถึงสิทธิของท่าน รวมถึงการปฏิบัติตามหน้าที่ตามกฎหมายเมื่อมี

หากไม่ให้ข้อมูลที่จำเป็น เช่น LINE User ID และคำสั่ง ระบบจะตรวจสิทธิ์ สั่ง build หรือแจ้งผลให้ท่านไม่ได้ หากเพิ่มวัตถุประสงค์ที่ต้องอาศัยความยินยอม ผู้ดูแลจะแจ้งและขอความยินยอมแยกต่างหาก

4. การส่งต่อและการเปิดเผยข้อมูล

บริการใช้ LINE สำหรับข้อความ, Vercel สำหรับเว็บไซต์และ webhook, GitHub สำหรับโค้ดและงาน build และ Upstash Redis สำหรับป้องกันเหตุการณ์ซ้ำ ข้อมูลที่จำเป็นจึงอาจถูกประมวลผลโดยผู้ให้บริการเหล่านี้ รวมถึงบนระบบนอกประเทศไทยตามที่ตั้งและเงื่อนไขของผู้ให้บริการ

repository ของโครงการเป็นสาธารณะ ข้อมูลประกอบ workflow เช่น รหัสคำขอและ LINE User ID ที่ส่งเป็น input อาจเข้าถึงได้ผ่านข้อมูล Actions หรือบันทึกงานตามสิทธิ์ของ GitHub ห้ามส่งข้อมูลลับหรือข้อมูลส่วนบุคคลของบุคคลอื่นผ่านคำสั่ง โค้ด หรือไฟล์ build ผู้ดูแลไม่ได้นำข้อมูลไปขายหรือใช้เพื่อโฆษณา

5. ระยะเวลาเก็บข้อมูล

  • รหัสเหตุการณ์สำหรับกันคำสั่งซ้ำใน Redis ตั้งให้อายุ 7 วัน
  • ไฟล์ build บน GitHub Actions ตั้งระยะเวลาเก็บ 14 วัน ส่วนบันทึกงานและข้อมูลประกอบ workflow เป็นไปตามการตั้งค่า retention ของ GitHub ใน repository
  • รายชื่อ User ID ที่อนุญาตเก็บไว้ระหว่างที่ได้รับสิทธิ์ใช้งาน และนำออกเมื่อผู้ดูแลยกเลิกสิทธิ์
  • บันทึกทางเทคนิคของ Vercel, LINE และผู้ให้บริการอื่นเป็นไปตามการตั้งค่า แผนบริการ และนโยบายของแต่ละราย ไม่ได้สิ้นสุดพร้อมอายุข้อมูล Redis โดยอัตโนมัติ
  • คำขอช่วยเหลือเก็บเท่าที่จำเป็นต่อการจัดการเรื่องนั้นหรือการปฏิบัติตามกฎหมาย จากนั้นลบหรือทำให้ไม่สามารถระบุตัวบุคคลได้ตามที่ทำได้

6. การรักษาความปลอดภัย

ระบบตรวจลายเซ็น webhook ก่อนอ่านคำสั่ง จำกัด User ID ผู้ใช้งาน เก็บ token ฝั่งเซิร์ฟเวอร์ และแยกงานแจ้งผลออกจากงาน build มาตรการเหล่านี้ช่วยลดความเสี่ยง แต่ไม่สามารถรับรองความปลอดภัยของระบบเครือข่ายหรือบริการภายนอกได้ทุกกรณี

7. สิทธิและช่องทางติดต่อ

ท่านอาจขอเข้าถึงหรือรับสำเนา แก้ไข ลบ จำกัดการใช้ คัดค้าน หรือขอรับและโอนข้อมูล รวมถึงถอนความยินยอมในกรณีที่ใช้ฐานความยินยอม ตามเงื่อนไขและข้อยกเว้นของกฎหมายที่ใช้บังคับ การถอนความยินยอมไม่กระทบการประมวลผลที่ชอบด้วยกฎหมายก่อนถอน และท่านมีสิทธิร้องเรียนต่อหน่วยงานกำกับดูแลที่เกี่ยวข้อง

ติดต่อผู้ดูแลผ่านแชต LINE Official Account ที่ท่านใช้บริการ โดยระบุว่าต้องการติดต่อเรื่องข้อมูลส่วนบุคคล หากติดต่อผ่าน LINE ไม่ได้ ให้เปิดคำขอติดต่อใน GitHub Issues ของโครงการ เพื่อประสานช่องทางส่วนตัว โดยไม่ใส่ User ID, token หรือข้อมูลส่วนบุคคลลงใน Issue สาธารณะ ผู้ดูแลอาจขอข้อมูลยืนยันตัวตนเท่าที่จำเป็นก่อนดำเนินการ

8. การเปลี่ยนแปลงนโยบาย

ผู้ดูแลจะเผยแพร่ฉบับปรับปรุงพร้อมวันที่มีผลบนหน้านี้ หากเปลี่ยนวัตถุประสงค์หรือการใช้ข้อมูลอย่างมีนัยสำคัญ จะแจ้งผ่านช่องทางบริการและดำเนินการตามที่กฎหมายกำหนด
