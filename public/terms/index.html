ข้อกำหนดการใช้บริการ

LINE × Godot Build · มีผลใช้บังคับวันที่ 3 พฤศจิกายน 2569

1. ขอบเขตบริการ

LINE × Godot Build เป็นเครื่องมือสำหรับสั่ง export โปรเจกต์ Godot ผ่านบอต LINE โดยใช้ Vercel รับคำสั่งและ GitHub Actions ประมวลผล ผู้ดูแลบริการคือเจ้าของบัญชี GitHub banyapon การส่งคำสั่งใช้งานหมายถึงท่านตกลงตามข้อกำหนดนี้ หากไม่ตกลง โปรดหยุดส่งคำสั่ง

2. ผู้มีสิทธิ์ใช้งาน

บริการเปิดให้เฉพาะ LINE User ID ที่ผู้ดูแลอนุญาต ผู้ใช้ต้องมีสิทธิ์เข้าถึง repository และสิทธิ์สั่งประมวลผลโปรเจกต์นั้น ห้ามใช้บัญชีหรือสิทธิ์ของผู้อื่นโดยไม่ได้รับอนุญาต ผู้ที่ต้องอาศัยความยินยอมจากผู้แทนตามกฎหมายต้องได้รับความยินยอมตามกฎหมายก่อนใช้งาน

3. คำสั่งและผลลัพธ์

  • build web และ build windows ใช้สั่ง export จาก branch ที่ผู้ดูแลตั้งค่าไว้
  • status และ logs ใช้ดูสถานะและเปิดหน้ารายละเอียดงานล่าสุด
  • รุ่นเริ่มต้นรองรับ Godot 4 รุ่น stable และ GDScript ต้องมีเวอร์ชัน export templates และ presets ตรงกับโปรเจกต์
  • ไฟล์ผลลัพธ์อยู่ใน GitHub Actions Artifacts ซึ่งตั้งอายุ 14 วัน การดาวน์โหลดขึ้นอยู่กับการเข้าสู่ระบบและสิทธิ์ของ GitHub
  • การ build สำหรับเว็บให้ไฟล์ export การเผยแพร่ลิงก์เปิดเล่นต้องตั้งค่าพื้นที่โฮสต์เพิ่มเติม

การตอบรับคำสั่งหมายถึงระบบส่งคำขอประมวลผลแล้ว ไม่ใช่การรับรองว่า build จะสำเร็จ หากระบบแจ้งการเชื่อมต่อผิดพลาด ให้ตรวจสอบ Actions ก่อนสั่งซ้ำ เพราะงานอาจเริ่มทำงานแล้ว

4. หน้าที่ของผู้ใช้

ท่านต้องมีสิทธิ์ใช้โค้ด รูปภาพ เสียง ฟอนต์ ส่วนเสริม และทรัพย์สินอื่นในโปรเจกต์ รวมถึงปฏิบัติตามใบอนุญาตและข้อกำหนดของบริการภายนอก ผู้ใช้ยังคงเป็นเจ้าของสิทธิ์ในผลงานของตนตามสิทธิ์ที่มีอยู่ และอนุญาตให้ระบบประมวลผลและจัดเก็บข้อมูลเท่าที่จำเป็นเพื่อดำเนินคำสั่ง

ห้ามส่ง malware, token, รหัสผ่าน หรือข้อมูลส่วนบุคคลที่ไม่มีสิทธิ์เปิดเผย ห้ามใช้บริการเพื่อโจมตีระบบ ขุดคริปโท ส่งคำสั่งถี่จนรบกวนผู้อื่น หลบเลี่ยงการควบคุมสิทธิ์ หรือละเมิดกฎหมายและสิทธิ์ของบุคคลอื่น repository สาธารณะอาจเปิดเผยโค้ดและข้อมูลประกอบงานได้ ผู้ใช้ควรตรวจสอบไฟล์และผลลัพธ์ก่อนเผยแพร่

5. ค่าใช้จ่ายและข้อจำกัด

ข้อกำหนดฉบับนี้ไม่ได้กำหนดค่าบริการที่โครงการเรียกเก็บจากผู้ใช้ การใช้งาน LINE, GitHub Actions, Vercel และ Upstash อาจใช้โควตาหรือมีค่าใช้จ่ายตามบัญชีและแผนของเจ้าของบริการแต่ละราย ผู้ดูแลจะต้องแจ้งเงื่อนไขแยกต่างหากก่อนเรียกเก็บค่าบริการใหม่จากผู้ใช้

ผู้ดูแลอาจจำกัดจำนวนคำสั่ง ระงับสิทธิ์ หรือหยุดให้บริการเพื่อป้องกันการใช้งานผิดวัตถุประสงค์ จัดการโควตา บำรุงรักษาระบบ หรือปฏิบัติตามกฎหมาย และจะแจ้งล่วงหน้าเมื่อทำได้

6. ความพร้อมใช้งานและความรับผิด

บริการอยู่ระหว่างพัฒนาและขึ้นอยู่กับระบบภายนอก จึงไม่รับรองว่าจะทำงานต่อเนื่อง ไม่มีข้อผิดพลาด หรือได้ผลลัพธ์ที่เหมาะกับทุกโปรเจกต์ ผู้ใช้ควรสำรองซอร์สโค้ด ตรวจสอบไฟล์ build และทดสอบก่อนนำไปใช้งานจริง

ความรับผิดของแต่ละฝ่ายเป็นไปตามกฎหมายที่ใช้บังคับ ไม่มีข้อความใดในข้อกำหนดนี้ตัดสิทธิ์ที่กฎหมายคุ้มครองผู้ใช้ หรือยกเว้นความรับผิดในกรณีที่กฎหมายห้ามยกเว้น

7. ข้อมูลส่วนบุคคลและบริการภายนอก

การประมวลผลข้อมูลเป็นไปตาม นโยบายความเป็นส่วนตัว รวมถึงการส่งข้อมูลที่จำเป็นไปยังผู้ให้บริการภายนอก การใช้งานบัญชี LINE, GitHub, Vercel และ Upstash อยู่ภายใต้เงื่อนไขของผู้ให้บริการแต่ละรายด้วย

8. การหยุดใช้บริการและการเปลี่ยนข้อกำหนด

ท่านหยุดใช้บริการได้ทุกเมื่อ และขอให้ผู้ดูแลนำ User ID ออกจากรายชื่อผู้มีสิทธิ์ได้ การหยุดใช้งานไม่ได้ลบบันทึกงานหรือข้อมูลบนบริการภายนอกทันที โปรดดูระยะเวลาเก็บและช่องทางใช้สิทธิ์ในนโยบายความเป็นส่วนตัว

ผู้ดูแลจะเผยแพร่ข้อกำหนดฉบับใหม่พร้อมวันที่มีผลบนหน้านี้ และแจ้งการเปลี่ยนแปลงสาระสำคัญผ่านช่องทางบริการ หากไม่ยอมรับฉบับใหม่ ท่านสามารถหยุดใช้งานก่อนวันที่มีผล

9. ติดต่อและการระงับข้อพิพาท

ติดต่อผ่านแชต LINE Official Account ที่ใช้บริการ หรือ GitHub Issues ของโครงการ สำหรับปัญหาทางเทคนิค ห้ามเผยแพร่ token หรือข้อมูลส่วนบุคคลใน Issue สาธารณะ ทั้งสองฝ่ายควรพยายามแก้ไขข้อขัดข้องร่วมกันก่อน โดยข้อกำหนดนี้อยู่ภายใต้กฎหมายไทยและไม่กระทบสิทธิ์หรือเขตอำนาจที่กฎหมายบังคับกำหนด
