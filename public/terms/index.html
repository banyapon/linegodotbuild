LINE Game Studio · มีผลใช้บังคับวันที่ 3 พฤศจิกายน 2569

1. บริการและผู้มีสิทธิ์

LINE Game Studio ดูแลโดยเจ้าของบัญชี GitHub banyapon เป็นเครื่องมือสร้างเกมเว็บผ่านแชต LINE สำหรับ User ID ที่ผู้ดูแลอนุญาต การส่งคำสั่งใช้งานหมายถึงยอมรับข้อกำหนดนี้ หากไม่ตกลง โปรดหยุดส่งคำสั่ง ผู้ใช้ต้องมีอำนาจใช้บัญชีและเนื้อหาที่ส่ง ผู้ที่ต้องอาศัยความยินยอมจากผู้แทนตามกฎหมายต้องได้รับความยินยอมตามกฎหมายก่อน

2. การสร้างและเผยแพร่เกม

  • new game, new 2d และ new space เริ่มเกมหน้าเดียวแนวตั้ง 9:16 พร้อม Virtual Joystick; new collector เลือกเกมเดินเก็บของ, new 3d ใช้ออกแบบเกมสามมิติ และ new vn สร้าง Visual Novel
  • ส่งภาพ PNG/JPEG เพื่อคัดลอกเข้า Cloudinary หรืออ้างอิง URL ภาพใน cloud ที่กำหนด แล้วระบุบทบาทภาพเป็นฉาก ตัวละคร เหรียญ หรือศัตรู
  • ผู้ช่วยใช้ Gemini เมื่อมีการตั้งค่า เพื่อออกแบบและถามว่าต้องการปรับอะไรต่อ เกมอิสระสร้างไฟล์ index.html และ index.js เก็บใน branch และรันใน browser sandbox รองรับ Canvas/DOM หรือ Three.js ที่จัดเตรียมไว้ โดยไม่รองรับการเรียก API ภายนอก การนำเข้าไลบรารีอิสระ หรือพื้นที่เก็บข้อมูล โค้ดจาก AI อาจมีข้อผิดพลาดและไม่รับรองกลไกทุกแบบ ผู้ใช้ควรทดสอบก่อนแบ่งปัน
  • พิมพ์ พอแล้ว เพื่อบันทึก branch และเผยแพร่เกมเป็น URL ที่แชร์ได้ การแก้ฉบับร่างไม่เปลี่ยนเกมที่เผยแพร่จนกว่าจะเผยแพร่อีกครั้ง
  • ใช้ projects, status และ open project_id เพื่อจัดการโปรเจกต์ของตน

ปัจจุบันรองรับไม่เกิน 20 ภาพต่อโปรเจกต์ ภาพละ 8 MB, 30 โปรเจกต์ต่อผู้ใช้ และ 20 คำสั่งต่อนาที อาจจำกัดเพิ่มเติมตามทรัพยากรและโควตา การตอบรับคำสั่งไม่ได้รับรองว่าประมวลผลสำเร็จแล้ว

3. สิทธิในผลงานและหน้าที่ผู้ใช้

ผู้ใช้คงสิทธิ์ในเนื้อหาของตนตามสิทธิ์ที่มีอยู่ และอนุญาตให้ระบบประมวลผล เก็บ ส่งต่อ และเผยแพร่เนื้อหาเท่าที่จำเป็นต่อคำสั่ง ต้องมีสิทธิ์ใช้ภาพ โค้ด ชื่อ ตัวละคร ฟอนต์ และทรัพย์สินที่ส่ง รวมถึงปฏิบัติตามเงื่อนไขผู้ให้บริการภายนอก

ห้ามส่งเนื้อหาที่ละเมิดสิทธิ์หรือกฎหมาย, token, รหัสผ่าน หรือข้อมูลที่ไม่มีสิทธิ์เปิดเผย ห้ามโจมตีระบบ หลบเลี่ยงสิทธิ์ ใช้โปรเจกต์ผู้อื่น หรือส่งคำสั่งรบกวนบริการ ผู้ใช้ต้องตรวจสอบเกมและเนื้อหา AI ก่อนนำไปใช้จริง

repository ปัจจุบันเป็นสาธารณะ แบบเกม บทสนทนาที่บันทึกใน branch และ URL ภาพจึงอาจถูกเข้าถึงได้ ผู้มีลิงก์เล่นเกมสามารถดูข้อมูลเกมที่เผยแพร่ได้ บริการรุ่นนี้ไม่ใช่พื้นที่จัดเก็บเนื้อหาลับ

4. การลบเกม

พิมพ์ x-delete ตามด้วย project_id ในเครื่องหมายอัญประกาศเพื่อลบเกมของตน ระบบจะปิดลิงก์ แล้วลบ branch และภาพที่โปรเจกต์นั้นอัปโหลด การลบอาจดำเนินการบางส่วนหากบริการภายนอกขัดข้อง ให้ส่งคำสั่งเดิมซ้ำเพื่อทำต่อ

ภาพที่นำ URL มาอ้างอิงไม่ได้ถูกลบจากต้นทาง การลบไม่รับรองว่าจะล้าง Git history, fork, CDN, ข้อมูลสำรอง หน้าเกมที่เปิดไว้ หรือสำเนาของผู้อื่นได้ทันที การลบเกมอาจไม่สามารถกู้คืนผ่านบริการนี้ได้ โปรดสำรองเนื้อหาที่ต้องการก่อนสั่งลบ

5. ค่าใช้จ่ายและความพร้อมใช้งาน

ฉบับนี้ไม่ได้กำหนดค่าบริการที่โครงการเรียกเก็บจากผู้ใช้ ผู้ให้บริการ LINE, Vercel, GitHub, Upstash, Cloudinary และ Gemini อาจคิดค่าบริการหรือใช้โควตาตามบัญชีและแผนของเจ้าของบัญชี ผู้ดูแลต้องแจ้งเงื่อนไขแยกก่อนเรียกเก็บค่าบริการใหม่จากผู้ใช้

บริการอยู่ระหว่างพัฒนาและพึ่งพาระบบภายนอก อาจขัดข้อง ล่าช้า หรือประมวลผลไม่ครบ ผู้ดูแลอาจจำกัดหรือระงับบริการเพื่อดูแลระบบ โควตา การใช้งานผิดวัตถุประสงค์ หรือหน้าที่ตามกฎหมาย และจะแจ้งเมื่อทำได้ ความรับผิดเป็นไปตามกฎหมายที่ใช้บังคับ โดยไม่มีข้อความใดตัดสิทธิ์ที่กฎหมายคุ้มครองหรือยกเว้นความรับผิดที่กฎหมายห้ามยกเว้น

6. ข้อมูลส่วนบุคคล การเปลี่ยนแปลง และการติดต่อ

การใช้ข้อมูลเป็นไปตาม นโยบายความเป็นส่วนตัว และเงื่อนไขบริการภายนอก ผู้ใช้หยุดใช้งานได้ทุกเมื่อและขอให้นำ User ID ออกจากรายชื่อสิทธิ์ได้ การหยุดใช้ไม่ลบข้อมูลทั้งหมดโดยอัตโนมัติ

ผู้ดูแลจะเผยแพร่ข้อกำหนดใหม่พร้อมวันที่มีผลและแจ้งการเปลี่ยนแปลงสาระสำคัญ หากไม่ยอมรับให้หยุดใช้งานก่อนวันที่มีผล ติดต่อผ่าน LINE Official Account ที่ใช้บริการ หรือ GitHub Issues โดยไม่เผยแพร่ข้อมูลส่วนบุคคลหรือ secret ในที่สาธารณะ ข้อกำหนดอยู่ภายใต้กฎหมายไทยและไม่กระทบสิทธิ์หรือเขตอำนาจที่กฎหมายบังคับกำหนด
